# 🎵 XVOX

**Your Music. Your Space. Your Sound.**

A premium offline music player for Android, built with Kotlin and Jetpack Compose.

---

### ✨ Features

- 🎧 Offline music playback
- 🎨 AMOLED-friendly premium UI
- 🎵 Playlists, favourites and queue
- 🎚️ Equalizer and audio effects
- 🎤 Lyrics support
- 🖼️ Dynamic album artwork and colours
- ⚙️ Customisable themes and settings

### 🛠️ Tech Stack

- Kotlin
- Jetpack Compose
- Media3 / ExoPlayer
- DataStore
- Coil 3

### 🚀 Build

```bash
git clone https://github.com/YOUR_USERNAME/XVOX.git
cd XVOX
./gradlew assembleDebug
```

### 📱 Requirements

- Android 8.0+ (API 26)
- JDK 17 for building
