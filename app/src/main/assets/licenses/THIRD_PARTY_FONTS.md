# Bundled font notices

XVOX bundles the following typefaces from the Google Fonts project:

- ABeeZee
- Caveat
- Comfortaa
- DM Sans
- Josefin Sans
- Lora
- Manrope
- Nunito
- Outfit
- Space Grotesk

Each listed typeface is distributed by its upstream Google Fonts directory under the SIL Open Font License, Version 1.1 (OFL-1.1). The matching `*-OFL.txt` file in this directory preserves its upstream copyright and reserved-font-name notice. Their source is also available at:

https://github.com/google/fonts/tree/main/ofl

These files are embedded unchanged for offline Android text rendering. Inter remains the default bundled XVOX UI font.
