# XVOX screenshots

Place real, unedited device captures for the project README in this directory.

## Recommended files

| File | Suggested capture |
|---|---|
| `01-home.png` | Home/library landing view |
| `02-search.png` | Search results |
| `03-now-playing.png` | Now Playing artwork and controls |
| `04-lyrics.png` | Lyrics presentation |
| `05-queue.png` | Queue management |
| `06-settings.png` | Appearance or playback settings |
| `07-widget.png` | Home-screen widget |

## Capture guidance

- Use a real Android 13+ device or emulator with the stable release build.
- Prefer PNG and portrait captures unless a landscape-only feature is being shown.
- Remove personal media titles, account information, notifications, and device identifiers before committing.
- Keep the original pixels: do not add watermarks, filters, or stretched mockups.
- Use descriptive, ordered filenames so README references stay stable.

When assets are ready, add a gallery to the root [`README.md`](../README.md).
